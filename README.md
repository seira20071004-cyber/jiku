# jiku

自分の軸を、日々の行動へ。目標の木と毎日の行動・記録をつなぐ、日本語の自己管理Webアプリです。

## 使い方

1. 「自分の木」で根となる人生の目標を編集し、子目標・具体的な行動を追加します。初期の目標は自由に編集できるサンプルです。日々の活動記録は空の状態から始まります。
2. 葉っぱごとに優先順位、継続型／完了型、有効／一時停止／完了、タスクを始めるモードを1つ設定します。
3. 葉っぱごとに1回の固定量と単位を設定します。アプリを開いて「余裕がある日／忙しい日／休む日」を選ぶと、そのモードに含まれるタスクの固定量が今日の記録へ反映されます。量を3段階に分ける必要はありません。
4. 統計で目標ごとの週間合計を確認し、必要な日だけカレンダーから量やモードを修正します。
5. 週次レビューで気づきと来週の方針を保存します。レビュー中の優先順位・モード変更は翌週月曜から反映されます。

木のノードをタップすると編集できます。親は編集フォームでも変更でき、ノードをドラッグして別のノードへ重ねても移動できます。背景のドラッグで移動、＋／−でズーム、「この枝を見る」で部分表示が可能です。子がある目標は枝、末端の目標は葉として自動描画されます。枝の太さは重要度を表しません。

## 起動・検証

3D表示にはThree.js、ビルドにはesbuildを使用します。Node.js 18以上でテストでき、Python 3でローカル配信できます。

```sh
npm run dev
# http://localhost:4173
npm run check
npm test
```

ローカル確認ではビルド後の `dist/` を配信します。公開版はGoogle認証を行うため、`npm run build` で生成する `dist/server/index.js` をCloudflare Workersへ配置します。

## データと保存

このバージョンは `localStorage` に保存します。サーバー保存・端末間同期はありません。公開版のログインはGoogle認証を使用します。ブラウザごと・サイトのURLごとに保存領域が分かれます。設定からJSONバックアップの書き出し・検証付き読み込みが可能です。シークレットモードの終了やブラウザデータの削除では記録を失うため、定期的にバックアップしてください。

- GoalNode: `nodes`（ID・親ID・名前）。階層数は固定せず循環移動を拒否。
- ActionSetting: `settings`（優先順位・種類・状態・登録モード）。
- DailyRecord: `records`（日本時間の日付をキーにした単一モード）。
- ActionLog: `logs`（日付と行動ID、実行時の名前・設定・目標パス）。目標を削除しても過去の実績は維持。
- WeeklyReview: `reviews`（月曜始まりの週、気づき・次週方針）。次週の設定は `pending` に保存して適用。

未記録はモード割合に含めません。実行チェックがない行動は実績不明です。「何もしなかった日」と未記録を区別し、休息へのペナルティは設けていません。完了型は実行チェックで完了となり、再開するには編集画面で有効に戻します。AI分析、クラウド同期、成長アニメーションは未実装です。

## 構成

- `dist/index.html`: エントリーポイント
- `dist/app.js`: 画面・SVGツリー・操作
- `dist/model.js`: データ・日付・履歴・集計・バックアップ検証
- `dist/style.css`: PC／スマホ対応レイアウト
- `tests/model.test.js`: 日付境界・木構造・履歴・週次設定などのテスト

外部フォントが使用できない場合は端末内のフォントにフォールバックします。

## ナビゲーションとGoogle認証

画面下のメニューはPC・スマホ共通で「自分の木・統計」の2項目です。カレンダーは統計内にあります。今日のモードと行動チェックは「自分の木」に統合しました。以前の `#home` リンクも自分の木へ案内します。

Google認証はサーバーでセッションを検証し、許可したGoogleアカウントだけがアプリ本体を利用できます。Google Cloudと公開先の秘密設定はソースと分離して管理します。[接続手順と現在の制約](docs/google-login.md)を参照してください。

## シンプル表示

木・月間カレンダー・モードの割合をそれぞれ画面全体に表示します。画面上の説明文、行動リスト、週次レビューへの案内、集計サマリー、フッターは非表示です。木の「今日のモード」とカレンダーの日付から、必要なときだけ記録を変更できます。目標や過去の記録データは保持します。

## 3Dの自分の木

Three.jsで描くオリジナルの3Dツリーです。目標の親子関係から枝を生成し、葉を一枚ずつ独立した形状で描きます。柔らかい光・木陰・風によるわずかな葉の揺れを加えています。既存の参考作品のコードやモデルは使用していません。

- ドラッグで回転、ホイール／ピンチ／＋−でズーム、⤢で全体に戻せます。
- 目標名または金色の葉を選ぶと編集できます。親目標の変更は編集フォームから行います。
- Aaボタンで目標名の表示を切り替えられます。
- 下部メニューは「自分の木・統計」の2項目。統計内でカレンダーとモードの割合を切り替えます。従来の #calendar リンクも統計内のカレンダーへ案内します。
- WebGLが利用できない環境では従来の平面表示へ切り替わります。動きを減らすOS設定にも対応します。
- 配置・カメラ・装飾は表示時に計算し、目標や履歴の保存形式は変えていません。

開発時は `npm ci` → `npm run build` → `npm run dev` の順で起動してください。Three.jsのライセンスは配信される `three-LICENSE.txt` に含まれます。

## 葉っぱごとの量と週間集計

葉っぱを押して「1回の固定量」を1つだけ保存します。ページ・時間・分・回・問・単語・個、または自由な単位を選べます。タスクごとに「休む日・忙しい日・余裕がある日」のいずれか1つを選びます。休む日のタスクは全モード、忙しい日のタスクは忙しい日と余裕がある日、余裕がある日のタスクは余裕がある日だけに含まれます。どのモードでも同じ固定量を使用します。週の目標量は任意です。

その日の初回起動時にモードを選ぶと、対象タスクの固定量を今日の記録へ自動反映します。モードを選び直しても重複しません。今日のタスク設定を変更すると今日の自動記録も更新し、過去の記録は保存時の設定を保持します。自動反映した量は設定量の集計で、実測値ではありません。実際の量と違う日だけ「今日の記録を調整」やカレンダーから修正できます。手動で修正した量はモードを変更しても保持します。

統計の「取り組んだ量」では、月曜始まりの週ごとに単位別の合計・日別の推移・行動ごとの量と目標に対する進み具合を表示します。「振り返る目標」から任意の枝や葉を選べます。ページと時間は別々に集計し、分と時間は時間へ換算します。過去の週は左右の矢印で確認できます。カレンダーの日付から過去の量を編集することもできます。

実績には記録時の名前・単位・目標の親子関係を保存し、木を後から移動・削除しても、その当時の実績は元の目標の履歴として残ります。既存のチェック記録は量を推測せず「量未記録」として合計から除外します。単位を変更した日の既存の記録は、記録時の単位のまま編集します。生活のモードは木全体の記録です。
